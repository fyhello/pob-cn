# R33: 投影缓存与权威数据展示

## 已完成

- Tooltip 始终以 PoB 官方 `rawLines` 重新走统一词典翻译，不再复用浏览器旧投影中的 `lines_cn`。
- 官方制作工坊中的底材类别和底材名统一通过锁定 `poe2.json.gz` 字典展示；权威 ID 仍只用于提交。
- 浏览器只持久化 canonical PoB 文档。完整 Build 投影在恢复时本来就不会使用，移除其序列化避免每次穿戴、替换和卸下阻塞主线程。
- 物品事务进行时拒绝重复点击，避免并发请求排队造成额外卡顿。

## 保证

- 物品合法性、装备槽校验、计算与 XML 保存仍由官方 PoB 执行。
- 所有底材和词缀展示继续从受版本锁定与差异门禁保护的词典读取，不在组件内维护逐条翻译表。
