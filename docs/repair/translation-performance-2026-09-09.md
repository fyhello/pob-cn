# 翻译显示性能回归修复

日期：2026-09-09。

## 根因与修改

三类修改收到官方响应后，都经过 `buildStore.ts` 的 `officialProjectionState`。它先调用 `localizeImportedBuild`，随后又对装备、珠宝调用 `localizeImportedItem`，并重复处理技能组。新的显示字段是可枚举 getter，第二次本地化中的对象展开会主动读取这些字段；`displayRows` 和依赖它的 `lines_cn` 各执行一次正文翻译。实际 BD 的 22 件物品因此在一次投影中触发 44 次正文处理，即使当前显示的是天赋页。

正文的多行模板起始检测还会扫描最多 5,431 条表达式，并在每条表达式检查时重新规范化同一行。普通译文缓存无法覆盖这段检测。

本次只修改两处产品代码：

- `cn/web/src/stores/buildStore.ts`：直接复用本次已完成本地化的物品、珠宝和技能组。保留 ID 校验、缺少于物品库的装备补入、同 ID 引用复用。
- `cn/shared/translation-runtime.mjs`：多行起始检测只规范化一次输入；命中和未命中结果均按语言包实例缓存，最多 8,192 条，超限淘汰最早输入。没有改变模板集合、顺序、参数处理或匹配语义。

没有修改词典、官方计算、HTTP 协议、保存格式或页面结构。缓存内容只是翻译匹配结果，不是 PoB 数值、计算结果或 BD 数据。

## 浏览器前后对照

使用同一份真实 BD 的副本、独立核心、独立临时存档库及 Chrome。修复前仅由隔离 Vite 服务读取修改前保存的两份源码；没有回退工作目录。前后各执行天赋、技能、装备五轮往返，每类 10 次，共 60 次真实修改。

天赋测试由官方核心返回的相邻可分配节点中选取生命节点 `19482`；技能按官方 `dpsPipeline.skillName` 选择实际伤害宝石 `Grim Pillars`，基础等级 20/19 往返；装备为项链卸下、装回。不会把图腾载体等级变化但伤害数值未变的操作当成有效显示样本。

从可信原生 `mousedown`、`change` 或 `click` 事件开始计时。等待新文档版本与侧栏新数值匹配，确认至少一个关键数值确实改变，再等待两次动画帧。首轮和第五轮逐项截图，并检查真实页面样式已加载、画布位于视口内。两次动画帧及截图是显示完成的保守确认，不是精确的物理屏幕首帧测量。

逐项核验结果：

- 每次只有一个修改请求、一个对应官方事务、一次官方 `BuildOutput`。
- 30 对匹配状态的全部官方数值、天赋集合、武器天赋模式、装备和珠宝装配、物品原文一致。
- 完整物品显示行、名称及“不生效”状态在修复前后相同。
- 每次浏览器保存的分享代码解码后，与该次官方事务返回的 XML 逐字一致；两端各自保存重开后文档和输出不变。
- 用户原始 JSON 存档字节不变。未操作正常服务中的用户 BD。

完整分段样本、XML、状态和截图保留在本机临时证据目录 `pob-translation-performance-4bSbRh`，没有加入仓库。

## 防止再次遗漏

此前状态事务测试用直接返回原值的函数替代了翻译，未覆盖真实 getter 契约。本次在 `cn/tests/web/canonical-build-store.spec.mjs` 接入真实翻译模块和 Pinia，断言应用投影、保存草稿不读取任何未显示字段；同时覆盖不在物品库中的装备和珠宝、数字/字符串 ID、简繁变化及同 ID 物品正文更新。

`cn/tests/web/translation-runtime-cache.spec.mjs` 验证命中、未命中、等价格式、多参数起始行、非法额外文本、语言/版本隔离以及容量淘汰。通过实际表达式调用计数验证重复输入不再扫描，不使用不稳定的单元测试毫秒阈值。

`cn/tests/browser/translation-performance.mjs` 保留真实三类修改的分段、显示及保存验收入口。没有增加生产计时器、模拟响应或临时成功路径。

## 复现命令

在项目根目录执行，所有路径由环境变量传入，不要求更改正常服务或导入用户当前网页。

```powershell
$env:POB_CN_PLAYWRIGHT_PATH = '<现有 Playwright 的 index.mjs 绝对路径>'
$env:POB_CN_BROWSER = '<Chrome 可执行文件绝对路径>'
$env:POB_CN_BROWSER_FIXTURE = '<真实 BD 的 JSON 存档绝对路径>'
node cn/tests/browser/translation-performance.mjs
```

需要前后对照时，修改前原样保存 `buildStore.ts` 和 `translation-runtime.mjs` 到单独目录，再设置 `$env:POB_CN_PERF_BASELINE_DIR = '<该目录绝对路径>'`。脚本仅在修复前测试服务中读取这些快照，之后自动验证当前实现；省略此变量则只验证当前实现。不得用整个仓库回退代替快照，更不能覆盖已有未提交的翻译修改。

显示回归可继续使用现有入口：

```powershell
$env:POB_CN_TRANSLATION_FIXTURE = $env:POB_CN_BROWSER_FIXTURE
node cn/tests/browser/unique-crafting.mjs
```
