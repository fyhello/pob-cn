# 多网页独立核心、共享存档与公共物品池

日期：2026-09-07。基线：`ad41e9c731f444ea68b8990734563372052b7085`。

## 功能边界

- 首次打开网页进入存档选择页，不默认打开存档，也不启动计算核心。
- 可新建空白流派、导入并保存、搜索、打开、重命名、删除、保存和另存为。
- 每个网页独立持有会话 ID、官方核心进程、请求队列和编辑草稿。同一存档可以同时打开，但编辑状态不共享。
- 共享的是已保存存档和公共物品池。同一存档的过期版本不能覆盖最新保存；用户可以另存或重新载入。
- 复制到公共物品池不移除或修改来源物品；加入目标 BD 时创建新的官方本地物品 ID。删除公共条目不删除已加入 BD 的副本。
- 公共物品的穿戴目标来自目标核心的官方槽位校验，天赋珠宝槽还必须在当前官方天赋树中已分配。加入并穿戴失败时回滚整个事务，不留下半成品。
- 未增加账号系统、云同步、多人权限、自动合并、历史版本系统或数据库。

## 身份与持久化

共享库默认位于 `%LOCALAPPDATA%\PoB-CN\library`，可通过 `POB_CN_DATA_DIR` 指定独立目录：

```text
library/
  .writer.lock
  builds/<UUID>.json
  items/<UUID>.json
```

名称不是文件路径。保存、重命名和删除都检查条目版本；写入先落临时文件并同步，再原子替换。写锁只允许一个服务写同一个库。异常退出后的失效 PID 锁可在重启时处理；损坏或无法确认归属的锁显式报错，不冒险覆盖。

网页草稿使用本页 `sessionStorage`，仅保存官方文档、名称和保存基准，不保存计算投影。`localStorage` 旧数据不会自动覆盖新文档或被删除；同一来源下提供手动导入旧版流派入口。浏览器存储按协议、主机和端口隔离，新端口不能直接读取旧端口的浏览器存档，可通过 PoB 分享代码导入。

首次导航和复制标签页都进入选择页；本页刷新从草稿创建新核心。关闭网页会释放会话，未保存或计算中的离开操作会触发确认。草稿不是正式存档，也不承诺浏览器关闭、清除站点数据或磁盘损坏后仍可恢复，应使用保存功能。

## 失败与资源

- 修改请求按本页会话和文档代次排队。切换文档后，未发出的旧操作取消，旧成功响应、失败响应和天赋回滚不能覆盖新文档。
- 切换存档先在新核心完成真实导入与投影校验，成功后才替换页面状态；坏导入保留原草稿。
- 核心超时或协议异常后终止该核心并拒绝未完成请求，不把迟到响应交给下一请求。不自动重放失败修改。
- 恢复点是最后确认的官方 XML，不是计算结果缓存。核心恢复重新载入该文档；会话被回收或服务重启后，可在页面恢复草稿。
- 每 30 秒心跳；默认最多 8 个会话，180 秒无活动且没有待处理请求才回收。关闭等待已接收队列完成。
- 官方自动保存仍允许执行，但文件落入各核心的私有临时目录，不用禁止写入的探针干扰官方生命周期。正常结束会清理该核心目录；强制终止服务可能留下临时目录。
- 本轮复杂 BD 的两个活跃核心工作集约 374–384 MiB/核心。这是采样值，不是内存上界。后台标签冻结或设备休眠后可能需要恢复草稿。
- 当前作为可信本机工具使用，不提供远程用户认证；不要作为公共网络服务暴露。

## 运行与复验

前端配置按环境变量 `POB_CN_BRIDGE_TARGET`、Vite 本机环境文件、默认 `http://127.0.0.1:3002` 的顺序选择目标，`/api` 与 `/health` 共用同一目标。非默认端口通过桥接的 `POB_CN_PORT` 和前端代理目标配套设置；`cn/web/.env*.local` 由 Git 忽略，不提交本机配置。同一共享目录不可启动多个写入服务。

前后端必须运行配套版本。仅前端热更新、代理仍指向旧单核心服务时，`POST /api/sessions` 会返回 404。`bridgeClient.ts` 区分接口不匹配、非 JSON 响应和无效会话，保留后端错误并附接口及 HTTP 状态，不以通用登录或会话失败提示掩盖版本问题。

可复用的浏览器验收脚本为 `cn/tests/browser/multi-build.mjs`，使用临时共享库、临时端口和真实核心，不操作正常用户页面。运行前提供已安装的 Playwright 模块路径和浏览器程序路径：

```powershell
$env:POB_CN_PLAYWRIGHT_PATH = '<Playwright 的 index.js 绝对路径>'
$env:POB_CN_BROWSER = '<Chrome 或 Edge 的可执行文件绝对路径>'
# 可选：包含 canonicalBuild.code 或存档 code 的本地 JSON，启用真实导入及天赋/技能/装备验收。
$env:POB_CN_BROWSER_FIXTURE = '<本地 BD 验收副本 JSON 绝对路径>'
node cn/tests/browser/multi-build.mjs
```

不指定 BD 副本时验证空白新建路径。脚本使用临时共享库和独立核心，证据目录由脚本输出；原始 BD、截图与本机存档不加入仓库。最新完整门禁结果见 `item-text-unsupported-2026-09-08.md`。
