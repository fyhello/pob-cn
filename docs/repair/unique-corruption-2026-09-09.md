# 传奇腐化成品编辑

## 范围与来源

传奇制作新增「腐化成品」编辑区，复用原有 `draft.kind = "unique"` 的选项、预览、提交及 XML 保存事务。普通制作、文本导入、计算模块、官方词缀库、翻译词典和存档格式未修改。

当前核心的 `src/Classes/ItemsTab.lua:2694` 明确标注尚未实现完整的新瓦尔石结果。此功能编辑目标成品，不模拟随机过程、概率或完整游戏制作可达性；未新增腐化加孔入口，原有通用孔位编辑保持原行为。

| 内容 | 权威来源与接入 |
| --- | --- |
| 适用词缀、来源与数量 | 临时读取官方 `CorruptDisplayItem()` 的来源列表、候选和显示控件数量。普通候选经官方 `GetModSpawnWeight()` 过滤，特殊来源独立处理 |
| 词缀内容 | `data.itemMods.Corruption` 的 ID、原文、标签、顺序和词缀组；不接受自由文本，不在网页维护候选表 |
| 倍率 | 当前生效显式词条的官方滑块回调负责归一化值到倍率的映射；由 `Item:BuildAndParseRaw()` 解析、保存并参与计算 |
| 翻译与不生效提示 | 复用统一物品翻译入口及原有物品预览组件 |

## 主要文件

- `cn/lua/unique-corruption.lua`：官方能力读取、结构指纹、输入校验及临时物品修改。
- `cn/lua/unique-crafting.lua`：增加腐化字段白名单和类型内调用，不另建保存事务。
- `cn/web/src/components/UniqueCorruptionEditor.vue`：独立编辑组件，支持来源、搜索、同组排除、词缀调值和倍率滑块。
- `cn/web/src/components/UniqueItemCraftingPanel.vue`：沿用请求合并、过期响应拒绝、最新预览保存限制；更换变体清除旧腐化草稿。
- `cn/web/src/types/uniqueCorruption.ts`：组件共享的草稿与能力类型。

## 保真与限制

- 草稿携带物品／变体／词条结构指纹；选项、预览和提交均经过同一校验。部位不符、非法来源、重复词缀组、超出数量、非法范围、隐藏行及过期指纹均拒绝。
- 药剂、咒符等官方不开放腐化的物品，以及镜像、圣化物品，腐化区只读。已有腐化标志不能通过此入口撤销；新草稿尚未保存时可以取消。
- 已有词缀只有在官方原文与元数据可唯一识别且适用于当前来源时才允许替换。未知附魔、额外状态或不符合当前候选的旧词缀保留并显示只读原因，后端同样拒绝替换。
- 调回 1 倍明确清除原倍率；未调整的隐藏变体倍率保持不变。涂油行保留。已识别腐化词缀的范围仅由腐化区控制，避免与普通滑块重复编辑。
- 临时控件只接收当前生效显式行，并保留到原行编号的映射，避免大型多选传奇对隐藏行做重复缩放检查。无 BD 计算结果缓存。
- 官方桌面保存回调不运行；临时替换的展示物品、弹窗入口与弹窗列表在成功、失败后均恢复。

## 验证结果

- 真实核心全目录回归通过：443 个模板、4,167 次普通范围调值、11 个多组选项模板、4 个变底材模板及历史变体往返。
- 新增腐化回归通过：鞋子移动速度词缀拒绝用于腰带，装备／珠宝候选隔离，药剂与咒符拒绝，特殊头盔 8 项来源，倍率上下限与还原，普通调值组合、隐藏行与未知附魔保留、非法输入和过期指纹拒绝。
- 真实事务覆盖创建、穿戴预览回滚、编辑保留 ID、副本分配 ID、XML 保存重开及与官方重算结果比较。最终额外状态保护和旧词缀只读拒绝路径已单独重跑通过。
- 浏览器检查通过：部位候选、来源、调值、切换变体、腐化物品保存／编辑／重开、公共池复制、双窗口隔离、普通制作、伤害与防御明细、配置及语言显示回归；页面错误为 0，390／1440 像素检查无横向溢出。
- 前台页面单次腐化调值输入至预览绘制为 156 毫秒，含 120 毫秒请求合并；选项请求 19 毫秒、响应至绘制 12 毫秒。腐化物品保存至浏览器显示为 176／151 毫秒。自动调值新增整 BD 对比请求为 0。这些是隔离测试 BD 的样本，不代表所有物品或大型 BD 的上限。
- 最初双窗口脚本测得约 2 秒，经请求／绘制分段确认是后台页绘制节流。计时前显式激活被操作页面后得到上述结果；未据此改动业务计算。

- agy 提供了接入点探索；最终独立复核超时，未计入通过结论。实现和最终验证由主代理完成。
