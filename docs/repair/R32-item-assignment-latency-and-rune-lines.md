# R32: 物品分配延迟与符文词缀翻译

## 已完成

- 物品穿戴、替换和卸下使用本次 HTTP 请求已载入的 canonical XML 作为失败回滚快照，不再重复调用 `SaveDB` 生成同一份快照。
- 物品词缀先识别 `Rune:` / `Runes:` 标签，再对标签后的官方模板做不区分大小写的整行匹配。
- 修复 `+#` 模板将数值中的正号重复匹配的问题；`+3% to all maximum Elemental Resistances while on full Runic Ward` 等官方词缀能完整投影为中文。
- Tooltip 直接使用已投影的中文词缀，避免同一行在展示阶段再次被拆词翻译。
- 缓存已翻译的官方原始词缀，减少每次完整 Build 投影后的重复翻译工作。

## 保证

- 穿戴和卸下仍由官方 PoB 校验槽位、重算输出、保存 XML；未引入本地装备状态或本地计算。
