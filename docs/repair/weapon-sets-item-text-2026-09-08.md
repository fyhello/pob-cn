# 武器组、专用天赋、装备文本与精魂修复

日期：2026-09-08。保留已有多会话、共享存档、公共物品池及性能修复。

## 实现

- `cn/lua/real-calc-adapter.lua`：通过官方 `itemsTab.controls.weaponSwap1/2.onClick` 切换当前装备集武器组，保留其主技能联动。使用既有构建事务、单次主计算、XML 导出、局部投影、失败恢复及会话版本校验。
- 天赋投影保留所有树的节点 `allocMode`，当前树同步给前端。计数取自官方 `PassiveSpec:CountAllocNodes()`；总分配数包含两组，组一、组二和升华单列，不使用固定天赋点数上限。
- 每次点击在进入队列前捕获分配模式，执行时使用队列最新文档和节点状态。调用官方 `AllocNode/DeallocNode` 处理路径、依赖撤销和公用路径提升，并对齐官方 `PassiveTreeView` 中关键天赋、珠宝槽的公用模式限制。
- `WeaponSetSelector.vue` 提供计算武器组 I/II。`PassiveTreeCanvas.vue` 单独提供公用/I/II 分配模式，公用金色、组一红色、组二绿色；不把不同专用组之间的边画成已激活连接。
- `ItemsPanel.vue` 显示当前组官方可见槽位，切换后不保留已隐藏槽位作为筛选目标；槽位状态使用统一词典，槽位图标避免长标签挤出固定尺寸。
- `ItemTextImport.vue` 提供原文预览、加入当前流派、加入并穿戴。接口 `/api/items/text-preview`、`/api/items/from-text` 复用 `item-transfer.lua` 的官方解析和事务，不经公共池中转，不放宽手工制作 draft。
- 原文限制为 64 KiB。合法底材的未支持词缀允许导入，原文保留并逐行高亮标记为不生效；非法输入和穿戴仍明确失败并整体回滚。判定依据与显示链路见 `item-text-unsupported-2026-09-08.md`。
- `SideStats.vue` 使用官方 `SpiritUnreserved / Spirit`，进度条取 `SpiritUnreservedPercent`，仅做 CSS 可视范围裁剪。真实零、缺失和负值分别保留，精魂不足显示红色，不在前端计算数值。

## 装备页右侧工具区

- `ItemsPanel.vue` 第三列上方为公共物品池，下方为源码输入、官方预览和导入操作；无额外粘贴导入弹窗。原装备槽、BD 物品库和制作工坊逻辑保留，可用宽度不足时工具区换行。
- `SharedItemPool.vue` 复用常驻与弹窗容器，列表和明细内部滚动。常驻时不自动抢焦点；顶部公共池入口滚动并聚焦本区域。装备页不重复挂载弹窗，其他页面保留公共池弹窗入口。
- 公共池仅在选中物品或显式刷新槽位时请求官方预览；BD、会话、选中条目版本变化只作废旧槽位，迟到及组件卸载后的响应不写回。
- 源码导入成功后清空原文与预览并显示结果；失败保留输入及错误。输入或 BD 版本变化作废预览，不自动重算；处理期间禁止重复提交。

## 已知边界

官方 `Item` 构造器调用 `sanitiseText`，会把不支持的 Unicode 字符改成问号。新入口在解析前检查有损转换并明确拒绝，不把乱码物品视为成功。当前验证英文游戏复制文本和英文 PoB 原文，不支持会发生有损转换的中文游戏原文。

官方 `src/`、计算公式、统一词典未修改。天赋分配模式不是当前计算武器组，也不存储计算结果。保存仍以官方 XML 为准。

- Pinia 队列测试覆盖连续点击间切换公用/I/II 后，已排队操作仍携带点击时模式。
- `cn/tests/browser/weapon-sets-item-text.mjs` 覆盖红绿天赋点击、刷新恢复、两页面隔离、武器切换、常驻工具区、源码预览与穿戴、逐行不生效标记、跨 BD 公共池复制与使用、来源 BD 不变、精魂 DOM 校验及画布像素检查。
- 浏览器脚本延后交付真实官方源码和公共池预览响应，在交付前修改 BD，确认两类旧预览被丢弃。连续三轮武器组往返切换没有额外预览请求，每次修改仍只有一个构建请求。
- 检查 1920、1440、1024 宽度的真实截图及溢出断言，宽屏第三列上下排列，较窄时工具区换行。公共池弹窗另检查 1440 与 390 宽度；这不代表全站手机布局已适配。
- `cn/tests/browser/multi-build.mjs` 复杂 BD 回归覆盖独立核心、天赋/技能/装备各三轮修改、保存冲突、另存、草稿恢复，以及其他页面的公共池复制、加入、穿戴和删除。早期一次保存请求出现 `Failed to fetch`，该轮未计为通过；补充网络失败日志后完整重跑通过，未发现可复现的保存逻辑回归。
- 功能验收历史样本中，天赋点击至数值 DOM 更新并经过两帧约 287-425 ms，武器切换约 125-574 ms；复杂 BD 天赋约 437-482 ms，技能约 585-645 ms，装备约 445-1072 ms。包含自动化开销，不是严格 A/B 基准，也不承诺所有 BD 的延迟上界。
- GitNexus 对树绘制报告 CRITICAL（9 个直接入口、8 条流程）；对新增 Lua/HTTP/Vue 符号覆盖不足，已直接核对调用点和状态生命周期，并以真实核心和浏览器测试补足。agy 只读核验超时，无独立评审结论。

执行 `npm run test:m3`、`npm run web:typecheck`、`npm run web:build` 和上述两组浏览器脚本。浏览器环境参数见 `multi-build-library-2026-09-07.md`，最新完整门禁结果见 `item-text-unsupported-2026-09-08.md`。
