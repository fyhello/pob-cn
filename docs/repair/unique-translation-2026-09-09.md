# 传奇制作与物品浮窗翻译修复验收

日期：2026-09-09。本记录针对本轮传奇漏译修复，保留此前翻译及性能修改；未提交、推送，未修改官方计算、物品事务、保存格式或页面布局。

## 根因与处理

漏译不只是少了几个英文键。此前实际物品身份、局部／全局语境、官方匿名参数格式及多行正文没有完整进入翻译匹配，静态语料检查也没有覆盖全部官方变体、调值和实际浮窗。

| 根因 | 本轮处理及边界 |
| --- | --- |
| 传奇背景与名称不能仅靠零散英文行对齐 | 按官方 FlavourText 身份、物品名称、底材与完整原文选择独立简繁游戏文本；历史原文不替换成新背景 |
| 精魂与附加伤害存在局部／全局同句异义 | 从核验过的有序 stat ID 和官方底材能力生成物品语境索引；未知底材不猜测 |
| 原生单参数使用 `{}`／`{:+d}`，与核心编号格式不匹配 | 仅在物品显示中将单 stat、单占位映射到参数 0；条件、格式、转换标记仍必须一致，多参数不推断顺序 |
| 动态类型、范围、来源和生成式珠宝句子未覆盖 | 补充可追溯原生映射及明确标记的 PoB 审核完整句式；参数只搬运官方字符串，内层名称未匹配时保留整句原文 |
| 检查单行模板不能代表实际物品显示 | 网页与离线审核共用多行及“不生效”分组，遍历官方目录、每组选项与范围 0／0.5／1，记录实际显示和身份 |
| 扩大语料后反复尝试多行匹配有性能风险 | 多行模板独立索引、必要字面片段预筛选，成功和失败匹配均作 8,192 条有界缓存；按语言包、语境、实体隔离，不缓存 PoB 计算 |

主要路径：

- `cn/pipeline/lib/item-translations.mjs`、`cn/pipeline/lib/native-translations.mjs`：身份映射、格式保真和词典生成。
- `cn/pipeline/sources/translations/reviewed.json`：统一审核来源，无业务私有词典。
- `cn/shared/item-translation.mjs`、`cn/shared/translation-runtime.mjs`：共用分组、完整模板匹配及有界缓存。
- `cn/web/src/utils/webTranslation.ts`、`UniqueItemCraftingPanel.vue`、`ItemCraftingStudio.vue`：传递实际物品身份，显示词条与变体。
- `cn/pipeline/lua/translation-corpus.lua`、`export-translation-corpus.mjs`、`update-translations.mjs`：全目录实际语料、覆盖报告和回退门禁。

## 浏览器与性能

使用真实 BD 的只读副本、独立临时存档库及官方核心，未操作正常服务中的用户存档。最终浏览器完整流程通过：截图传奇、动态珠宝、重复选项、迟到响应隔离、调值合并、编辑保存、公共池、多窗口、保存重开、普通制作、计算二级明细、来源浮窗、天赋珠宝正文和消耗公式。八类页面切换显示语言均为 0 次业务请求，文档和数值不变，未捕获页面错误。1440／390 宽度检查通过；已检查实际截图中的中文、数值及“不生效”高亮。

此前一次完整浏览器测试在切回物品预览时超时，未计为通过。停止其他重任务后，未经放宽超时或跳过断言的同一测试完整通过；不能由此确定首次超时的唯一原因。

性能基线是**本轮传奇补译之前、已经包含上一轮延迟修复**的五份文件快照；不是最早的两秒回归版本。前后各执行天赋、技能、装备五轮往返，每类 10 次，共 60 次真实操作。从可信浏览器输入到侧栏显示新的官方数值，再等待两帧；不以核心返回作为终点。两个阶段顺序运行，测试期间未并行执行生成、M3 或另一浏览器任务。
